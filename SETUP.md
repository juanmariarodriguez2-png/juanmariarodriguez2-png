# Setup

This profile is rendered as terminal windows. Every image in `/assets` is an SVG
generated by `scripts/generate.mjs` (Node, zero dependencies) from the GitHub
GraphQL API. The workflow `.github/workflows/update-svgs.yml` re-runs it daily
and commits the SVGs only when they change.

```
scripts/
  content.mjs        ← all the profile text (edit this)
  generate.mjs       ← fetches stats, writes assets/*.svg
  lib/svg.mjs        ← themes, layouts, terminal window primitives
  lib/sections.mjs   ← one renderer per README section
assets/              ← 7 sections × {wide, narrow} × {dark, light} = 28 SVGs
```

## 1. Let the Action push commits

1. Go to **Settings → Actions → General**.
2. Under **Workflow permissions**, select **Read and write permissions**, then **Save**.

The workflow also asks for `contents: write` itself, but the repository setting
must allow it.

## 2. Run it once

**Actions → Update profile SVGs → Run workflow**. After that it runs:

- every day at 04:17 UTC,
- on every push to `main` that touches `scripts/**` or the workflow.

If nothing changed, the run ends with "SVGs unchanged, nothing to commit".

## 3. (Optional) Include private contributions

The built-in `GITHUB_TOKEN` only sees public activity. To count private
contributions and private repositories too:

1. Make sure **Settings (your profile) → Public profile → Contributions & activity →
   Include private contributions on my profile** is enabled.
2. Create a token: **Settings → Developer settings → Personal access tokens →
   Tokens (classic) → Generate new token**, with scopes `read:user` and `repo`
   (`repo` is only needed to read private repositories' languages).
3. In this repository: **Settings → Secrets and variables → Actions → New repository
   secret**, name it `GH_PAT`, and paste the token.

The workflow picks up `GH_PAT` automatically when it exists. Remove the secret to
go back to public-only data.

## Run locally

```bash
# With the GitHub CLI logged in:
GITHUB_TOKEN=$(gh auth token) npm run generate

# PowerShell:
$env:GITHUB_TOKEN = (gh auth token); npm run generate
```

Optional environment variables: `GH_USER` (another login) and `INCLUDE_PRIVATE=true`.

## Editing

- **Text** (intro, projects, stack, contact): edit `scripts/content.mjs` and push.
  The Action re-renders right away.
- **Colours**: `THEMES` in `scripts/lib/svg.mjs`.
- **Hide a language** from the neofetch breakdown (e.g. `HTML`): add it to
  `excludedLanguages` in `scripts/content.mjs`.

The renderer checks every line against its window width and fails the run instead
of producing an SVG that overflows.

## How it adapts

Each section in `README.md` is a `<picture>` with four sources:

| Viewport | Theme | File |
|---|---|---|
| ≤ 600 px | dark | `<section>-narrow-dark.svg` |
| ≤ 600 px | light | `<section>-narrow-light.svg` |
| desktop | dark | `<section>-dark.svg` |
| desktop | light | `<section>-light.svg` |

The narrow variants (420 px wide) stack the `whoami`/`neofetch` windows and turn
the projects table into a list, so text stays readable on phones. Animations
(typing, heatmap fade-in, blinking cursor) are pure CSS inside the SVG and are
disabled when the viewer has `prefers-reduced-motion` turned on.
